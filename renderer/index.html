      Transcription

      Uses the OpenWhispr app's local model, so audio never leaves this Mac. The app opens OpenWhispr in the background if it isn't running. Pick or download models in OpenWhispr's own settings.

      Create a key in OpenWhispr under Integrations → API with the transcriptions:write scope. Cloud transcription is in beta: Pro or Business plan, 4 MB per file.

      Claude summaries

      Only needed for summaries. Get a key at console.anthropic.com.

      Notion

      Only needed for uploads. Create an integration at notion.so/profile/integrations, then on the parent page open ••• → Connections and add it.

      Recorders

      Plug in a voice recorder (or any drive with recordings) and Anvil Notes lists the recordings it hasn't processed yet. Recordings are remembered once processed or marked as done.

      Ignored drives: none
